# Scent-Mail — Ridiculous at First Glance, Real by the Second

A one-sentence pitch for a bizarre startup that actually pencils out:
**Scent-Mail** bottles a long-distance lover's smell — a worn shirt, fresh
rain, home cooking — and mails it to their partner, because lonely couples
pay postage for a whiff worth a thousand video calls.

`main.py` (Python stdlib only) writes that single sentence to
`/output/entry.txt`.
